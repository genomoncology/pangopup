# Measure complete sparse-index latency against fixed-v1

The complete sparse candidate passed size and logical parity, but ADR 0027 still has no authoritative latency result. Add one maintainer-only, side-by-side benchmark and run it on the retained Ryzen 7 5825U reference host. Keep fixed-v1 active and change no asset identity or route.

## Acceptance

- The benchmark opens the complete immutable fixed member and complete sparse candidate in one release process. The fixed member must be 15,033,158,255 bytes with SHA-256 `6fd8eb490e643728f6682fe6fc1910b88641354aaa221781575763c4ca94bf27`. The sparse member must be 2,035,371,437 bytes with SHA-256 `354343dc1a9f6558e46693e2481b5181461be2115cd92e029ffd4d4abef4a01e`.
- The checked-in query manifest must be 6,938 bytes with SHA-256 `e1d8ffb9bf0077d7b48acf49bb436d7e7453ed3abb3497269b87e09c722aa0bd` and contain 100 strictly ordered gene-filtered SNVs. The retained 134-gene selection must be 6,569 bytes with SHA-256 `056c974c64bfc78b42640b58cb548ec95d7cfe0fca8edcf2f5c19f2a35985a70`. ADR 0027 clarifies before measurement that these files supply request provenance while the timed readers use complete installed-layout members.
- Before timing, both readers answer all 100 requests identically. Equality covers ordered records and ambiguities, including genes, scores, and relative positions. Each timed operation consumes and checks its result so the optimizer cannot remove lookups.
- Workloads use the first 1, 10, and 100 manifest requests. Detailed equality checks run before the timer. A timed operation contains only release-mode reader calls, record and ambiguity length accumulation, an identical optimizer barrier, and result destruction. The harness checks the returned totals after stopping the timer. For warmup and retained sample number zero and every other even number, fixed runs before sparse; odd numbers reverse the order. Each reader receives 20 warmups and 20 retained warm one-open samples per workload. The report retains every nanosecond sample and computes nearest-rank p50 exactly as ADR 0027 defines.
- For each workload, the report records fixed and candidate p50, candidate/fixed ratio without lossy floating-point gate decisions, the ten-times result, the 2,100 / 19,640 / 195,880 ns absolute result, and the combined pass result. Boundary, overflow, sample-count, ordering, manifest, identity, and cross-reader mismatch tests fail closed.
- The closed canonical JSON report records its schema, method, command commit, release executable identity, target, kernel, Ubuntu release, CPU, process affinity, CPU governor and energy preference, memory, storage model, input identities, both request-provenance identities, raw samples, p50 values, exact ratio operands, and gate results. It refuses the run unless it sees the retained AMD Ryzen 7 5825U host, Ubuntu 24.04, all 16 default allowed CPUs, the recorded Crucial CT1000P3PSSD8 storage model, regular input files, and an absent output path. This retains the historical unpinned scheduling condition instead of introducing CPU 0 pinning.
- Build with `cargo build --release --locked` from a clean exact pushed checkout. Record and cross-check `git rev-parse HEAD`, clean status, `rustc --version --verbose`, target, and executable SHA-256 before running on an otherwise idle reference host. Record the pre-run process/load observation, command, report identity, raw and summarized results, and honest limitations in `planning/artifacts/0133-sparse-index-latency.md`. Commit the canonical raw report as `planning/artifacts/0133-sparse-index-latency-report.json`.
- Document the benchmark command and result boundary in `architecture/index.md`, and update `planning/frontier.md` with the observed result and remaining gates. Focused tests, strict builder lint, `make lint`, `make test`, `make spec`, and `git diff --check` pass on macOS. The exact pushed command commit passes focused tests on Linux AMD64 before measurement.

## Excluded

Do not activate or package the candidate, change any identity or route, change the format, weaken ADR 0027, claim cold-I/O behavior, run semantic service qualification, or complete the remaining corruption and rollback gates.
