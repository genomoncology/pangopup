# A deterministic streaming writer produces sparse SNV candidate bytes

The candidate-only `pangopup_index::sparse_writer` module now writes `pangopup.sparse-direct.v1` bytes from the same complete-gene `InputLocus` stream used by fixed-v1 production building. It leaves the fixed-v1 writer, reader, bundle opening, manifests, profiles, assets, and routing unchanged.

The writer validates gene and coordinate order, duplicates, alternate sets, `REF=N` shapes, and relative score positions. A failed submission poisons it. Disk payload and exception spools use create-new paths. Final assembly reads held spool descriptors and syncs a create-new sibling stage. It verifies and removes both writer-owned scratch inodes before publication. Cleanup failure prevents publication, and Drop retries cleanup. Replaced scratch paths remain untouched. Publication uses an atomic no-replace hard link and accepts bare relative outputs by syncing `.`.

The format uses a fixed header and ordered gene, segment, and block directories. Bounded 4,096-locus blocks encode two-bit references, active flags, 64-locus ranks, six-bit gain/loss masks, and compact score-position pairs. Fixed reserved bytes are zero. Checked arithmetic covers lengths, offsets, counts, products, sums, and conversions.

`crates/pangopup-index/tests/sparse_writer.rs` independently decodes the candidate bytes and compares every field. It checks gene segment starts, segment counts, ordinary counts, physical sections, directory order, every rank checkpoint pair, every stored score pair, and every reserved byte. Mutation cases alter each of those fields and require decoding to fail or the logical stream to differ. Its miniature varies scores by alternate and places partial gain/loss masks around rank 64 and block 4,096 boundaries. It also covers overlap, coordinate gaps, every reference base, default records, zero scores at nondefault positions, both admitted `REF=N` shapes, the maximum coordinate, invalid input, poisoning, deterministic bytes, path preservation, cleanup, and a bare relative output. Module tests inject spool, final-assembly, and cleanup failures and preserve a replaced scratch path.

`crates/pangopup-build/tests/sparse_heap_bound.rs` measures creation, every submitted gene, and finish in one process with a tracking allocator. A concurrent Linux sampler covers resident memory during final assembly. The 1,500,000-locus nondefault-score run produced 20,083,756 bytes from 19,903,500 scratch bytes. Peak heap grew 440,675 bytes, maximum retained heap grew 196,905 bytes, and finish retained zero bytes on the final macOS run. Linux resident evidence remains pending.

The focused sparse writer and heap tests pass on macOS. `make lint`, `make test`, `make spec`, and `git diff --check` also pass. The specification gate passed 193 blocks. This ticket adds no reader, lookup, complete-genome build, benchmark, installed candidate, or ADR 0027 qualification claim.
