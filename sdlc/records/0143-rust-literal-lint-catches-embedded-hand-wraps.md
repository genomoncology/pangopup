# Rust literal lint catches embedded hand wraps

The Rust literal continuity gate now follows the lexical states that can change a quote's meaning. It rejects an unescaped physical newline in an ordinary, byte, or C string and retains the existing rejection of three or more spaces between word characters inside those strings. A trailing backslash remains an accepted continuation. Character and byte-character literals, lifetimes, labels, line comments, nested block comments, and raw, raw-byte, and raw-C strings with exact hash delimiters cannot create false string boundaries. Unterminated strings, character literals, and block comments report their path and opening line.

The first red run added draft 0103's two-line ordinary literal to the old harness. The old line-oriented check exited 1 because its own fixture assertion reported that it did not refuse `crates/other/src/embedded-wrap.rs`. The repaired fixture set pins that miss, the prior collapsed-space finding, ordinary and byte continuations, escaped quotes and backslashes, a character containing `"`, lifetimes, labels, comments, C strings, and raw delimiters that close only on the matching hash count.

Eighteen exact exemptions preserve the aligned `LEGACY_USAGE` value and the repository's seventeen deliberate multiline SQL literals. Each exemption binds a finding kind, path, line, and complete opening source line. A copied value, a defective neighbor, or a moved, removed, or changed exemption target fails. The supported grammar and its boundary are recorded in `tests/support/rust-literal-scan.md`.

The scanner advances through each checked physical line once and jumps across raw-string content to a matching delimiter candidate. The focused gate checked 108 Rust sources and a generated 1,402,788-byte fixture. `make lint`, `make test`, `make spec`, and `git diff --check` passed on macOS. The specification gate ran 205 blocks. The scanner remains a bounded lexical check. It does not parse Rust expressions, macros, types, or names. Draft 0103 is archived with this ticket.
