# Runtime-v2 preparation and semantic gates are executable

PangoPup now prepares deterministic inactive `runtime-grch38-v2` release metadata bound to the qualified sparse SNV authority. Preparation preserves all eight model-side transport members byte for byte, keeps converter, tooling, and target commits distinct, and records a verified three-file source supplement. Preliminary manifest admission uses a held nonblocking file descriptor, a 1 MiB bound, and identity checks. Oversized input, FIFO replacement, and regular-file replacement fail without output. The v1 preparation and production selector remain unchanged.

One executable gate now compares the fixed and sparse formats across 1,000 requests, seven command groups, real service routing, overlap and filtered overlap, ambiguous reference, model fallback, invalid input, and all six position-one rejections. Each explicit miss runs through both formats. Mixed rejection batches produce no partial command output. The comparison validates identities from the admitted bundles and changes only the five permitted identity fields. Negative tests reject missing, wrong, shared, and unrelated identity changes. The gate requires exactly one executed and passed test for each selection and rejects missing, duplicate, ignored, zero-run, or malformed results. It creates a private cache home before running the product.

Independent design review accepted the corrected authority and evidence boundaries. Independent code review rejected the first version for overly broad identity replacement, masked miss cases, incomplete real-service coverage, a gate that accepted ignored tests, a skipped specification, and unsafe preliminary manifest reading. Two remediations closed those findings and a broad-gate cache-isolation failure. The final review accepted the result. `make lint`, `make test`, `make spec`, and `git diff --check` passed on macOS. The specification gate ran 205 blocks.
